ICS Maker / 它是什麼，以及替代方案

ICS Maker 是什麼

免費、無須帳號的行事曆檔案產生工具，完全在瀏覽器中執行。了解它的功能、限制，以及何時應選擇其他工具。

填寫標題、地點、日期和時間、時區、重複、受邀人、提醒和備註，然後下載 .ics 檔案或直接在行事曆中開啟。您也可以貼上日程，或附加文件或相片，一次建立多個活動。

ICS Maker 是什麼、適合誰使用，和其他替代方案相比又如何？

ICS Maker 可在瀏覽器中免費建立行事曆活動。你可以將單一活動匯出為 .ics、jCal、CSV 或 JSON-LD，或開啟適用於 Google 日曆、Outlook.com、Office 365 或 Yahoo 的預填連結。透過表單、貼上的時程表或附件收集活動，檢查辨識內容後，將它們一起下載為一個 .ics 檔案。無須帳號，不上傳活動資料，也不會在兩次造訪之間保存活動。它適合分享行事曆檔案或在網站中嵌入表單，但不管理行事曆、不收集出席回覆、不託管訂閱，也不保證能從所有文件中準確擷取活動。

它能做什麼

建立並收集活動
建立包含標題、地點、備註和 URL 的活動；收集多個活動，並將它們一起下載為一個 .ics 檔案。
在本機讀取時程表
貼上文字，或附加文件、試算表或圖片，然後檢查並修正辨識出的活動，再進行下載。不會上傳活動資料。
時間、全天，以及時區
開始與結束時間、可依兩者其中之一計算的持續時間、全天開關，以及一個 IANA 時區——若是航班，結束時間還能設定另一個不同的時區。
重複
每日、每週、每月或每年，每 N 個週期一次，結束方式可以是永不結束、達到指定次數後結束，或在特定日期結束——並寫成標準的 RRULE 那一行。
賓客、提醒與行程狀態
最多 100 個受邀者地址，以 ATTENDEE 行呈現；最多 10 個提醒，以 VALARM 區塊呈現；以及以 TRANSP 表示忙碌或空閒。
四種格式與四種連結
可下載 .ics、jCal、CSV 與 schema.org JSON-LD；可開啟 Google 日曆、Outlook.com、Office 365 與 Yahoo。
供您自己網站使用的嵌入版本
同一套建立工具，只需一個 script 標籤即可使用，壓縮後不到 85 kB，本身不會發出任何網路請求。

它做不到什麼

以下大多是「沒有伺服器」這個取捨所帶來的結果，而整個工具正是建立在這個取捨之上。之所以列出這些，是因為若一個工具被描述成能做到這些事，就會被推薦給真正需要這些功能的人，結果卻讓對方失望。

寄送任何東西
沒有郵件伺服器。受邀者地址只會被寫進檔案裡；不會有人收到郵件通知，除非您自行附加該檔案，或將它匯入到能夠寄送邀請的行事曆中，否則不會有任何邀請寄出。
收集出席回覆
回覆會以郵件形式寄給主辦人。下載下來的檔案沒有信箱可言，因此所有人的 PARTSTAT 都會停留在 NEEDS-ACTION。
託管可訂閱的動態消息
行事曆訂閱是指一個會被行事曆重新抓取的網址。ICS Maker 給您的是一個檔案；要讓檔案保持在一個穩定且會更新的網址上，屬於代管工作的範疇，而非建立工具的範疇。
儲存、列出或編輯過去的事件
什麼都不會被儲存——不會存在伺服器上，也不會在瀏覽器裡跨次造訪保留。關閉分頁，事件在這裡的生命就結束了。
保證自動擷取準確
文件和試算表會以文字方式讀取，並非透過可對應欄位的匯入工具處理。請檢查標題、日期和時間。自由敘述的文字及掃描版 PDF 可能需要貼上文字或附加照片。
選擇系列事件落在每月的哪一天
BYDAY、BYMONTHDAY、BYSETPOS 與 EXDATE 是需要在下載檔案中手動編輯一行文字才能完成的，並非表單控制項可以設定的。

適合誰使用

要把事件寄給一群使用什麼行事曆都無法猜測的人——檔案在任何地方都能用，但從一家公司的行事曆伺服器寄邀請到另一家有時候行不通。想讓事件只存在於收件人的行事曆裡，中間不建立任何帳號，也不夾帶任何追蹤連結。需要看看 RRULE、VALARM 或 TZID 正確寫法長什麼樣子的開發者。以及任何想在頁面上加入事件建立工具，卻不想引入廠商、不想加上會回傳資料的腳本、也不想背上每月帳單的人。

若需要追蹤出席回覆，或在他人儲存活動後進行修改，請使用你自己的行事曆。ICS Maker 產生可下載的檔案，不管理或同步行事曆。

與其他方案相比

您自己行事曆的匯出功能
免費、早已安裝好，而且當您需要收集出席回覆時，這才是正確答案——建立事件、邀請他人，再匯出 .ics 檔。缺點是需要帳號、會把您標記為主辦人，而且 Outlook 與 Google 各自用不同方式表示時區，不少「時間差一小時」的匯入問題就是從這裡開始的。
代管型的「加入行事曆」服務
能讓您取得點擊分析、設計過的按鈕，以及一個儀表板——若您正在衡量某個行銷活動的成效，這筆費用值得付。但這也代表您的頁面上會多一個第三方腳本、要依瀏覽次數或席位計價，而且訪客的事件資料會經過別人的伺服器。ICS Maker 的嵌入版本沒有這些分析功能，也不收取任何費用。
寫在您自己程式碼裡的程式庫
ical.js、ics，或 Python 的 icalendar 可以用程式化方式產生檔案，適合任何需要大量產出事件的系統。但對於今天只需要一份正確檔案的人來說，這些工具的形式並不合適，而且無論用哪一個，RFC 規定的跳脫與換行折疊規則仍然得由您自己處理正確。
手動撰寫檔案
完全可行——它本來就是純文字檔——也是學習這種格式的好方法。但 CRLF 換行、75 位元組的行折疊、逗號跳脫，以及缺少的 VTIMEZONE，往往會悄悄地毀掉一個在文字編輯器裡看起來完全正常的檔案。

常見問題

ICS Maker 是免費的嗎？
是的，沒有付費方案會限制功能，不需要建立帳號，也沒有使用次數限制。可嵌入版本也一樣：一個靜態的腳本檔案，沒有金鑰，也不依瀏覽次數收費。
ICS Maker 會儲存或看到我建立的事件嗎？
不會。事件是由在您自己瀏覽器中執行的 JavaScript，根據您輸入的內容組裝而成，並交付到您的下載資料夾：沒有伺服器可以儲存它，跨次造訪之間也不會保留任何東西，關閉分頁後不會在任何地方留下副本。此頁面唯一發出的請求，是取用它自己在 icsmaker.com 上的檔案——包括您第一次附加圖片時，從本站抓取的文字辨識程式，好讓辨識傳單這件事也在您自己的裝置上完成。您輸入或附加的任何內容都不會離開分頁，而此頁面上的內容安全政策（Content-Security-Policy）也以瀏覽器會強制執行的方式來保證這一點，而不只是要求您單憑信任接受的一句承諾。
ICS Maker 能寄送邀請或追蹤誰已接受邀請嗎？
不能。它沒有郵件伺服器，也沒有帳號系統，因此只會把賓客以 ATTENDEE 行的形式寫進檔案，僅止於此。若要收集出席回覆，請將下載的檔案匯入您自己的行事曆，並從那裡寄出邀請——您的行事曆會成為主辦方，並負責收集回覆。
什麼時候應該改用別的工具？
當您需要收集出席回覆，或想在寄出事件後還能修改它時，請使用您自己的行事曆。當您需要對某個行銷活動進行點擊分析時，請使用代管型的「加入行事曆」服務。當您自己的軟體必須大量產生事件時，請使用像 ical.js 或 Python 的 icalendar 這類程式庫。ICS Maker 適用的情境，是您只需要一份在瀏覽器中建立、不儲存在任何地方的正確檔案，僅此而已。
我可以把它建立的事件用於商業用途嗎？
可以。這份檔案是您的資料——這個工具只是用 iCalendar 格式來表達它——它所產生的內容沒有附帶任何署名要求、浮水印或授權條款。
