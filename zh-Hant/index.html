建立 ICS 行事曆檔案

建立活動、貼上時程表，或附加文件或傳單。檢查活動後，下載一個 .ics 檔案。免費，無須註冊，所有處理均在瀏覽器中完成。

填寫標題、地點、日期和時間、時區、重複、受邀人、提醒和備註，然後下載 .ics 檔案或直接在行事曆中開啟。您也可以貼上日程，或附加文件或相片，一次建立多個活動。

如何在不用帳號的情況下建立行事曆事件檔案（.ics）？

ICS Maker 是免費的線上 iCalendar（.ics）檔案產生工具。輸入活動標題、開始和結束時間，下載檔案後即可匯入 Google 日曆、Outlook 或 Apple 行事曆。你也可以貼上時程表或附加文件、圖片，檢查辨識出的活動，再將多個活動一起下載為一個 .ics 檔案。表單支援時區、重複規則、受邀者和提醒，也支援 jCal、CSV、JSON-LD 和行事曆連結。無須帳號：文字辨識、文件讀取和檔案產生均在瀏覽器中執行，不會上傳你的活動資料。

如何建立 ICS 檔案

  1. 在表單中輸入活動標題、開始和結束時間。
  2. 若活動與特定地點相關，請選擇時區；若要保留輸入的當地鐘面時間，請不要設定時區。
  3. 視需要加入重複規則、提醒、地點或備註，然後下載 .ics 檔案。
  4. 在行事曆應用程式中開啟檔案，或使用 Google 日曆設定中的匯入與匯出功能。

將時程表、文件或照片轉換為行事曆活動

使用另一個輸入分頁貼上時程表，或附加文件、試算表或傳單。ICS Maker 會在本機讀取文字並收集辨識出的活動。檢查每個標題、日期和時間，修正標示的欄位，再將收集的活動下載為一個 .ics 檔案。你也可以從表單將活動加入清單。

格式規律的時程表比自由敘述的文字更容易辨識。圖片文字辨識可能出錯；不明確的日期需要檢查。對於掃描版 PDF，請附加其中一頁的照片或貼上文字。匯入下載的檔案會複製活動，不會建立自動更新的行事曆訂閱。

可產生的格式

.ics（iCalendar）
Apple 日曆、Google 日曆、Outlook、Thunderbird——通用的檔案格式。
jCal
以 JSON 格式呈現的相同事件（RFC 7265）——適合偏好解析 JSON 而非 iCalendar 的應用程式。
CSV
Google 日曆與 Outlook 的試算表匯入工具，適用於批次或特殊情況。
JSON-LD
schema.org/Event 標記，讓搜尋引擎與瀏覽器能夠從頁面中讀取事件資訊。

為什麼它要求的資訊這麼少

沒有帳號，因為在瀏覽器中建立的事件不需要任何伺服器。頁面只載入一次，之後就不再與任何對象通訊：檔案是根據您輸入的內容組裝而成，並交給您自己的下載資料夾。關閉分頁後，任何地方都不會留下副本。

常見問題

什麼是 .ics 檔案？
.ics 檔案是一種純文字的行事曆事件，採用 RFC 5545 定義的 iCalendar 格式。所有主流行事曆——Apple 日曆、Google 日曆、Outlook、Thunderbird——都能讀取它，這也是為什麼在兩家不同公司之間以電子郵件寄送的邀請，仍然能正確顯示在雙方的行事曆中。
我需要帳號嗎？
不需要。這個頁面沒有註冊、沒有登入，也沒有伺服器端元件。事件是在您的瀏覽器中組裝並從那裡下載，因此您輸入的任何內容都不會被上傳。
這是免費的嗎？
是的，而且沒有付費方案會限制功能。同一個建立工具也提供可嵌入您自己網站的小工具版本。
事件會保留時區嗎？
只有在您選擇時區的情況下才會。預設情況下，事件不會帶有時區資訊，因此無論加入到哪裡，都會依照您輸入的時鐘時間開啟——這通常就是本地約會所需要的效果。當事件與特定地點相關時，請從清單中選擇一個時區，這樣每位賓客看到的時間都會轉換成他們自己的時區。
事件的結束時區可以和開始時區不同嗎？
可以。選擇開始時區後，勾選「結束於不同時區」並選擇第二個時區。檔案會在開始與結束時間各自標示一個時區，這正是航班應有的記錄方式——班機在倫敦時間 15:00 起飛，於紐約時間 11:00 降落。
