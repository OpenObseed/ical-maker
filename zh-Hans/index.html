创建 ICS 日历文件

创建活动、粘贴日程表，或附加文档或传单。检查活动后，下载一个 .ics 文件。免费，无需注册，所有处理均在浏览器中完成。

填写标题、地点、日期和时间、时区、重复、受邀人、提醒和备注，然后下载 .ics 文件或直接在日历中打开。您也可以粘贴日程，或附加文档或照片，一次创建多个活动。

如何在没有账户的情况下创建日历事件文件（.ics）？

ICS Maker 是免费的在线 iCalendar（.ics）文件生成工具。输入活动标题、开始和结束时间，下载文件后即可导入 Google 日历、Outlook 或 Apple 日历。你也可以粘贴日程表或附加文档、图片，检查识别出的活动，再将多个活动一起下载为一个 .ics 文件。表单支持时区、重复规则、受邀者和提醒，还支持 jCal、CSV、JSON-LD 和日历链接。无需账号：文字识别、文档读取和文件生成均在浏览器中运行，不会上传你的活动数据。

如何创建 ICS 文件

  1. 在表单中输入活动标题、开始和结束时间。
  2. 如果活动与某个地点相关，请选择时区；如需保留输入的当地钟表时间，请不设置时区。
  3. 按需添加重复规则、提醒、地点或备注，然后下载 .ics 文件。
  4. 在日历应用中打开文件，或使用 Google 日历设置中的导入和导出功能。

将日程表、文档或照片转换为日历活动

使用另一个输入选项卡粘贴日程表，或附加文档、电子表格或传单。ICS Maker 会在本地读取文字并收集识别出的活动。检查每个标题、日期和时间，修正标出的字段，然后将收集的活动下载为一个 .ics 文件。你也可以从表单向列表中添加活动。

格式规整的日程表比自由叙述的文本更容易识别。图片文字识别可能出错；含糊的日期需要检查。对于扫描版 PDF，请附加某一页的照片或粘贴文字。导入下载的文件会复制活动，不会创建自动更新的日历订阅。

它生成的格式

.ics（iCalendar）
Apple 日历、Google 日历、Outlook、Thunderbird——通用文件格式。
jCal
以 JSON 格式表示的同一事件（RFC 7265）——适用于更倾向于解析 JSON 而非 iCalendar 的应用。
CSV
用于 Google 日历和 Outlook 的电子表格导入工具，适合批量或特殊情况。
JSON-LD
schema.org/Event 标记，方便搜索引擎和浏览器从页面中读取事件信息。

为什么它要求这么少

无需账户，因为在浏览器中创建的事件不需要任何人的服务器。页面只加载一次，之后不再与任何服务器通信：文件由您输入的内容组装而成，并交付到您自己的下载文件夹。关闭标签页后，任何地方都不会留下副本。

常见问题

什么是 .ics 文件？
.ics 文件是符合 RFC 5545 所定义的 iCalendar 格式的纯文本日历事件。所有主流日历应用——Apple 日历、Google 日历、Outlook、Thunderbird——都能读取它，这也是为什么在两家不同公司之间通过电子邮件发送的邀请，仍能正确显示在双方的日历中。
我需要账户吗？
不需要。该页面没有注册、没有登录，也没有服务器组件。事件在您的浏览器中组装并从那里下载，因此您输入的任何内容都不会被上传。
它是免费的吗？
是的，并且没有付费套餐会限制功能。同一个创建工具还可作为可嵌入的小组件，供您在自己的网站上使用。
事件会保留其时区吗？
只有在您选择时区的情况下才会保留。默认情况下，事件不带任何时区信息，因此无论在哪里添加，它都会按照您输入的时钟时间打开——这通常正是本地约会所需要的。当事件与特定地点相关联时，请从列表中选择一个时区，这样每位宾客看到的时间都会转换为他们各自的时区。
事件的结束时区可以与开始时区不同吗？
可以。选择一个起始时区，然后勾选“结束于不同时区”并选择第二个时区。该文件会为开始时间和结束时间分别标注时区，这正是航班信息应有的记录方式——例如从伦敦当地时间 15:00 起飞，在纽约当地时间 11:00 降落。
