.ics 文件详解

.ics 文件是以纯文本形式写成的一个或多个日历事件,采用所有日历应用都认可的通用格式。您可以在下方创建一个,或者了解它内部究竟包含什么。

填写标题、地点、日期和时间、时区、重复、受邀人、提醒和备注，然后下载 .ics 文件或直接在日历中打开。您也可以粘贴日程，或附加文档或照片，一次创建多个活动。

什么是 .ics 文件?

.ics 文件是以纯文本形式写成的一个或多个日历事件,采用 iCalendar 格式,该格式于 2009 年被标准化为 RFC 5545,此后一直未变。事件内容位于 BEGIN:VEVENT 和 END:VEVENT 之间,其中 SUMMARY 是标题,DTSTART 和 DTEND 是时间,LOCATION 和 DESCRIPTION 顾名思义,UID 则是日历用来区分更新事件与新事件的标识符。Apple 日历、Google 日历、Outlook 和 Thunderbird 都能读取该格式,这也是为什么在两家公司之间通过邮件发送的邀请能够正确显示在双方日历中。ICS Maker 可以根据表单生成文件,并在您输入时实时显示文件的确切内容。

其中包含什么内容

用文本编辑器打开 .ics 文件,它会显示为一份简短的属性列表。事件本身位于 BEGIN:VEVENT 和 END:VEVENT 之间:SUMMARY 是标题,DTSTART 和 DTEND 是时间,LOCATION 和 DESCRIPTION 与其字面意思一致,而 UID 则是日历用来区分更新事件与新事件的标识符。该格式为 RFC 5545,发布于 2009 年,此后一直未变——这就是为什么今天写出的文件也能在十年前编写的软件中打开。

表单旁边的预览就是真实的文件内容,会随着您的输入实时更新。这里没有任何隐藏内容,也没有任何额外添加:您在此看到的内容与下载文件的内容逐字节完全一致。

如何打开这类文件

macOS 和 iOS
双击或点按该文件,"日历"应用会提示您添加该事件。
Google 日历
依次进入"设置"→"导入和导出"→"导入",然后选择文件以及要导入到的日历。
Outlook
依次选择"文件"→"打开并导出"→"导入/导出"→"导入 iCalendar (.ics) 文件",或者在 Windows 中直接双击该文件。
Android
大多数 Android 日历应用是通过网页版 Google 日历导入,而不是直接从手机导入——请将文件发送到自己的邮箱,并在电脑上打开。

常见问题

ICS 是什么的缩写?
它只是 iCalendar 数据的文件扩展名——"iCalendar Stream"的缩写。该格式本身由 RFC 5545 定义,相同的内容有时也以 text/calendar 的媒体类型提供。
.ics 和 iCal 是同一回事吗?
几乎是。iCal 曾是苹果公司的日历应用名称(现在简称为"日历"),人们借用了这个名字来指代它所读取的格式。该格式的正式名称是 iCalendar,其文件以 .ics 结尾。
一个 .ics 文件可以包含多个事件吗?
可以。一个 .ics 文件可包含多个 VEVENT 块。在 ICS Maker 中，通过表单、粘贴的日程表或附件收集活动。检查并修正后，即可将它们一起下载为一个 .ics 文件。导入会复制活动，不会创建日历订阅。
我可以手动编辑 .ics 文件吗?
可以,这也是修正拼写错误的合理方式——它是纯文本文件,每行对应一个属性。请保持行尾为 CRLF 格式,并保留长行的折行处理,否则严格的解析器可能会报错。
