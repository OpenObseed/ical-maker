빌더를 내 사이트에 직접 넣기

이 페이지의 생성기는 하나의 컴포넌트이며, 독립형 번들 형태로 제공됩니다. 페이지에 스크립트 태그 하나, 마운트할 요소 하나만 있으면, 방문자는 사이트를 떠나지 않고도 직접 이벤트를 만들 수 있습니다.

제목, 장소, 날짜와 시간, 시간대, 반복, 참석자, 알림, 메모를 입력한 다음 .ics 파일을 내려받거나 캘린더에서 바로 여세요. 일정을 붙여 넣거나 문서 또는 사진을 첨부해 여러 일정을 한 번에 만들 수도 있습니다.

내 사이트에 일정 추가 버튼이나 이벤트 빌더를 넣으려면 어떻게 해야 하나요?

ICS Maker의 빌더는 독립형 스크립트로 제공됩니다: 빈 요소 하나, event-creator.js를 가리키는 스크립트 태그 하나, 그리고 EventCreator.mount() 호출 하나면 됩니다 — 빌드 과정도, 프레임워크도, 계정도, 키도, 뷰당 제한도 필요 없습니다. 이 번들은 렌더링 라이브러리가 포함된 상태로 gzip 압축 시 85kB 미만인 단일 독립형 IIFE이며, 네트워크 요청을 전혀 하지 않습니다 — 분석 도구도, 폰트도, CDN도 없으므로 콘텐츠 보안 정책(CSP)에 추가할 출처도, 개인정보 처리방침에 추가할 문단도 없습니다. 모든 색상, 모서리 반경, 글꼴은 .ec-root 아래의 CSS 사용자 지정 속성으로 정의되며, 다크 모드는 방문자의 설정을 그대로 따르고, React 사이트라면 번들을 불러오는 대신 컴포넌트를 직접 렌더링할 수 있습니다.

스크립트 태그 하나로

<div id="event-creator"></div>
<script src="https://icsmaker.com/event-creator.js"></script>
<script>
  EventCreator.mount('#event-creator', { showPreview: false });
</script>

이 번들은 자체 렌더링과 자체 스타일을 갖추고 있어 별도로 설치할 의존성이 없습니다. 어디와도 통신하지 않습니다 — 분석 도구도, 폰트도, CDN도 없습니다 — 그러므로 사이트의 개인정보 처리방침에 새 문단을 추가할 필요도, 엄격한 콘텐츠 보안 정책에 새 출처를 추가할 필요도 없습니다.

내 사이트처럼 보이게 만들기

모든 색상, 모서리 반경, 글꼴은 .ec-root 아래의 CSS 사용자 지정 속성이므로, --ec-accent를 재정의하는 것만으로 테마 작업이 대부분 끝납니다. 다크 모드는 방문자의 설정을 자동으로 따르며, 공간이 부족한 경우 showPreview: false로 미리보기 패널을 끌 수 있습니다.

이미 React를 사용 중이신가요?

번들 대신 컴포넌트를 직접 렌더링하세요 — 폼 로직은 동일하며, 페이지에 렌더링 라이브러리 사본이 하나 더 늘어나는 것을 피할 수 있습니다.

자주 묻는 질문

임베드가 서버로 무언가를 전송하나요?
아니요. 이것은 방문자의 브라우저 안에서만 완전히 실행되는 정적 파일입니다: 분석 도구도, 텔레메트리도, 서버로의 호출도 없습니다. 이 도메인에서 번들을 불러오고 싶지 않다면 직접 호스팅할 수도 있습니다.
크기는 얼마나 되나요?
렌더링 라이브러리를 포함해 gzip 압축 시 85kB 미만이며, 페이지를 차단하지 않고 페이지 로드 후에 불러와집니다. 번들이 이 크기를 넘어서면 빌드가 실패하도록 되어 있어, 이 페이지에 적힌 수치가 슬그머니 거짓이 되는 일은 없습니다.
방문자가 다운로드할 수 있는 형식을 제한할 수 있나요?
mount 호출은 기본 형식, 기본 날짜, 미리 채워진 초안, 미리보기 표시 여부 등의 옵션을 받으며, React 컴포넌트도 동일한 값을 props로 받습니다.
