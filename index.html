Build a calendar event and download it as a file — or drop it straight into Google, Outlook, Office 365, or Yahoo. No signup, no upload: the file is generated in your browser.

How do I create a calendar event file (.ics) without an account?

ICS Maker (icsmaker.com) is a free web page that turns a filled-in form into a calendar event file. Type the title, location, start and end, time zone, repeat, guests, alerts, and notes, then take the event as .ics (iCalendar, RFC 5545), jCal (RFC 7265), a CSV row for a bulk importer, or schema.org JSON-LD — or copy a prefilled link for Google Calendar, Outlook.com, Office 365, or Yahoo. There is no signup, no paid tier, and no upload: the event file is assembled by JavaScript in the browser and never sent anywhere. On icsmaker.com the page makes no network requests at all once it has loaded — a deployment can enable an optional describe-it box that sends the typed sentence to an LLM proxy, and that box is the only thing here that ever opens a connection.

Title, location, date and time, time zone, repeat, invitees, alerts, and notes — then download the .ics file or open it straight in your calendar.

Formats it generates

.ics (iCalendar)
Apple Calendar, Google Calendar, Outlook, Thunderbird — the universal file.
jCal
The same event as JSON (RFC 7265) — for anything that would rather parse JSON than iCalendar.
CSV
Google Calendar and Outlook's spreadsheet importer, for bulk or awkward cases.
JSON-LD
schema.org/Event markup, so search engines and browsers can read the event off a page.

Why it asks so little

There is no account, because an event you build in your browser needs nobody’s server. The page loads once and then talks to nothing: the file is assembled from what you typed and handed to your own download folder. Close the tab and there is no copy left anywhere.

Questions

What is an .ics file?
An .ics file is a plain-text calendar event in the iCalendar format defined by RFC 5545. Every mainstream calendar — Apple Calendar, Google Calendar, Outlook, Thunderbird — reads it, which is why an invitation emailed between two different companies still lands correctly in both calendars.
Do I need an account?
No. The page has no signup, no login, and no server component. The event is assembled in your browser and downloaded from there, so nothing you type is uploaded.
Is it free?
Yes, and there is no paid tier holding features back. The same builder is also available as an embeddable widget for your own site.
Will the event keep its time zone?
Only if you choose one. By default the event carries no time zone, so it opens at the clock time you typed wherever it is added — usually what you want for a local appointment. Pick a zone from the list when the event is tied to one place, and every guest sees it converted to their own.
Can an event end in a different time zone from the one it starts in?
Yes. Pick a start zone, then tick "Ends in a different time zone" and choose the second one. The file carries a zone on the start and another on the end, which is exactly how a flight is meant to be written — it leaves at 15:00 in London and lands at 11:00 in New York.
